# 第三方网络资源下载接口实现分析

## 接口实现说明

**下载服务端实现 (`DownloadController`)**

该控制器提供了两种下载方式：
1. GET 方式下载 (`/downloadGet`)
2. POST 方式下载 (`/downloadPost`)

核心方法 `sendFile` 实现了文件下载功能，特点包括：
- 模拟大文件下载（每次写入后休眠500ms）
- 设置响应头指定文件类型和文件名
- 使用流式传输，避免内存溢出

```java
@GetMapping("/downloadGet")
public void download(HttpServletResponse response) {
    sendFile(response);
}

@PostMapping("/downloadPost")
public void download(@RequestBody Map<String, String> body, HttpServletResponse response) {
    System.out.println(">>>>:" + body);
    sendFile(response);
}

private void sendFile(HttpServletResponse response) {
    response.setHeader("Content-Disposition", "attachment;filename=" +fileName);
    response.setHeader("Content-Type", MediaType.APPLICATION_OCTET_STREAM_VALUE);
    try (
            FileInputStream fis = new FileInputStream("C:\\Users\\^\\Desktop\\" + fileName);
            ServletOutputStream os = response.getOutputStream();
    ) {
        response.setContentLength(fis.available());
        byte[] b = new byte[100 * 1024]; // 每次下载100kb
        int len;
        while ((len = fis.read(b)) > 0) {
            os.write(b, 0, len);
            System.out.println(">>>>: File server send byte length: " + len);
            Thread.sleep(500); // 模拟大文件下载
        }
        os.flush();
    } catch (Exception e) {
        e.printStackTrace();
    }
}
```

## 客户端下载实现 (`TestController`)

### 1. 普通下载方式 (`/common`)

特点：
- 使用 `RestTemplate` 的 `exchange` 或 `getForEntity` 方法
- 先完整获取资源再写入响应
- 缺点：会阻塞，下载大文件时内存占用高

```java
@GetMapping("/common")

    ResponseEntity<Resource> response = restTemplate.exchange("http://127.0.0.1:9998/test/downloadGet", HttpMethod.GET, null, Resource.class);
    // 处理响应...
}
```

### 2. 流式下载方式1 - GET (`/stream1`)

特点：
- 使用 `restTemplate.execute` 方法
- 流式处理，边下载边写入响应
- 设置响应头告知浏览器文件大小
- 更高效，适合大文件下载

```java
@GetMapping("/stream1")
public void stream1(HttpServletResponse response1) {
    // 设置响应头
    restTemplate.execute(
            "http://127.0.0.1:9998/test/downloadGet",
            HttpMethod.GET,
            request -> {
                // 设置请求头
            },
            response -> {
                // 流式处理响应...
                return null;
            });
}
```

## 性能对比

| 下载方式       | 特点                             | 适用场景                     |
| -------------- | -------------------------------- | ---------------------------- |
| 普通下载       | 简单易用，但会阻塞且内存占用高   | 小文件下载                   |
| 流式下载(GET)  | 边下载边传输，内存占用低，效率高 | 大文件下载                   |
| 流式下载(POST) | 支持传递参数，边下载边传输       | 需要传递参数的大文件下载场景 |

## 最佳实践建议

1. **大文件下载**：务必使用流式下载方式，避免内存溢出
2. **进度显示**：可以在流式传输中添加进度计算逻辑
3. **错误处理**：增强异常处理，特别是网络中断情况
4. **断点续传**：可考虑添加Range头支持断点续传功能
5. **安全考虑**：对下载文件名进行安全检查，防止路径遍历攻击

## 第三方网络资源下载接口

```java
**
 * 第三方网络资源下载接口控制器
 * 提供文件下载的GET和POST接口
 */
@RestController
@RequestMapping(value = "/test")
public class DownloadController {
    // 定义要下载的文件名
    public static String fileName = "a.zip";

    /**
     * GET方式下载文件接口
     * @param response HttpServletResponse对象，用于向客户端发送文件
     */
    @GetMapping("/downloadGet")
    public void download(HttpServletResponse response) {
        sendFile(response);
    }

    /**
     * POST方式下载文件接口
     * @param body 请求体中的参数Map
     * @param response HttpServletResponse对象，用于向客户端发送文件
     */
    @PostMapping("/downloadPost")
    public void download(@RequestBody Map<String, String> body, HttpServletResponse response) {
        System.out.println(">>>>:" + body);  // 打印接收到的请求体参数
        sendFile(response);
    }

    /**
     * 发送文件到客户端
     * @param response HttpServletResponse对象
     */
    private void sendFile(HttpServletResponse response) {
        // 设置响应头：指定为附件下载方式，并设置文件名
        response.setHeader("Content-Disposition", "attachment;filename=" +fileName);
        // 设置响应头：指定内容类型为二进制流
        response.setHeader("Content-Type", MediaType.APPLICATION_OCTET_STREAM_VALUE);
        try (
                // 创建文件输入流，读取指定路径的文件
                FileInputStream fis = new FileInputStream("C:\\Users\\^\\Desktop\\" + fileName);
                // 获取响应输出流
                ServletOutputStream os = response.getOutputStream();
        ) {
            // 设置响应内容长度
            response.setContentLength(fis.available());
            // 定义100KB的缓冲区
            byte[] b = new byte[100 * 1024];
            int len;
            // 循环读取文件并写入响应输出流
            while ((len = fis.read(b)) > 0) {
                os.write(b, 0, len);
                System.out.println(">>>>: File server send byte length: " + len);
                Thread.sleep(500); // 模拟大文件下载（每次写入后休眠500ms）
            }
            os.flush();  // 刷新输出流
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

## 客户端下载

```java
/**
 * 客户端下载控制器
 * 提供三种不同的下载方式
 */
@RestController
@RequestMapping(value = "/test")
@SuppressWarnings("all")
public class TestController {

    // 创建RestTemplate实例用于HTTP请求
    private final RestTemplate restTemplate = new RestTemplate();

    /**
     * 普通下载方式 - 会阻塞且速度慢
     * @param response1 HttpServletResponse对象
     */
    @GetMapping("/common")
    public void common(HttpServletResponse response1) {
        // 设置响应头：指定为附件下载方式，并设置文件名
        response1.setHeader("Content-Disposition", "attachment;filename=" + DownloadController.fileName);
        // 设置响应头：指定内容类型为二进制流
        response1.setHeader("Content-Type", MediaType.APPLICATION_OCTET_STREAM_VALUE);
        // 执行请求并获取网络文件
        // 三个参数：请求地址，请求方式，请求体，响应体类型
        ResponseEntity<Resource> response = restTemplate.exchange("http://127.0.0.1:9998/test/downloadGet", HttpMethod.GET, null, Resource.class); // Resource 是 Spring 提供的接口，通常用于表示文件或流数据。
        // 另一种请求方式（注释掉）
        // ResponseEntity<Resource> response = restTemplate.getForEntity("http://127.0.0.1:9998/test/downloadGet", Resource.class);

        // 检查响应状态和响应体
        if (response.getStatusCode() == HttpStatus.OK && response.getBody() != null) {
            try (
                    // 获取输入流
                    InputStream inputStream = response.getBody().getInputStream();
                    // 包装为缓冲流
                    BufferedInputStream bis = new BufferedInputStream(inputStream);
                    // 获取响应输出流
                    ServletOutputStream os = response1.getOutputStream();
            ) {
                // 定义8KB的缓冲区
                byte[] buffer = new byte[8192];
                int len;
                // 循环读取并写入响应输出流
                while ((len = bis.read(buffer)) != -1) {
                    os.write(buffer, 0, len);
                    System.out.println("download byte and send to browser, byte length:" + len);
                }
                os.flush();  // 刷新输出流
            } catch (Exception e) {
                e.printStackTrace();
            }
        }
    }

    /**
     * 流式下载方式1 - GET请求
     * @param response1 HttpServletResponse对象
     */
    @GetMapping("/stream1")
    public void stream1(HttpServletResponse response1) {
        // 设置响应头
        response1.setHeader("Content-Disposition", "attachment;filename=" + DownloadController.fileName);
        response1.setHeader("Content-Type", MediaType.APPLICATION_OCTET_STREAM_VALUE);
        
        // 使用RestTemplate执行请求
        restTemplate.execute(
                "http://127.0.0.1:9998/test/downloadGet",  // 请求URL
                HttpMethod.GET,  // 请求方法
                request -> {
                    // 设置请求头
                    request.getHeaders().set("Accept", "application/octet-stream");
                    // 可以设置认证头（注释掉）
                    // request.getHeaders().set("Authorization", "token");
                },
                response -> {
                    // 获取响应体输入流
                    InputStream inputStream = response.getBody();
                    // 包装为缓冲流
                    BufferedInputStream bis = new BufferedInputStream(inputStream);
                    // 获取响应输出流
                    ServletOutputStream os = response1.getOutputStream();
                    // 设置响应内容长度
                    response1.setContentLength((int)response.getHeaders().getContentLength());
                    // 定义8KB的缓冲区
                    byte[] b = new byte[8096];
                    int len;
                    // 循环读取并写入响应输出流
                    while ((len = bis.read(b)) > 0) {
                        os.write(b, 0, len);
                        System.out.println("download byte and send to browser, byte length:" + len);
                    }
                    // 关闭流
                    bis.close();
                    os.flush();
                    os.close();
                    return null;
                });
    }

    /**
     * 流式下载方式2 - POST请求
     * @param response1 HttpServletResponse对象
     */
    @GetMapping("/stream2")
    public void stream2(HttpServletResponse response1) {
        // 设置响应头
        response1.setHeader("Content-Disposition", "attachment;filename=" + DownloadController.fileName);
        response1.setHeader("Content-Type", MediaType.APPLICATION_OCTET_STREAM_VALUE);
        // 使用RestTemplate执行请求
        restTemplate.execute(
                "http://127.0.0.1:9998/test/downloadPost",  // 请求URL
                HttpMethod.POST,  // 请求方法
                request -> {
                    // 设置请求头
                    request.getHeaders().set("Accept", MediaType.APPLICATION_OCTET_STREAM_VALUE);
                    // 可以设置认证头
                    // request.getHeaders().set("Authorization", "token");
                    // 设置请求体内容类型
                    request.getHeaders().setContentType(MediaType.APPLICATION_JSON);
                    // 创建请求参数Map
                    Map<String, String> map = new HashMap<>();
                    map.put("a", "a");
                    map.put("b", "b");
                    // 将参数写入请求体
                    request.getBody().write(JSON.toJSONString(map).getBytes(StandardCharsets.UTF_8));
                },
                response -> {
                    // 获取响应体输入流
                    InputStream inputStream = response.getBody();
                    // 包装为缓冲流
                    BufferedInputStream bis = new BufferedInputStream(inputStream);
                    // 获取响应输出流
                    ServletOutputStream os = response1.getOutputStream();

                    byte[] b = new byte[8096];
```
