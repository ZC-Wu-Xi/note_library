导入最新的项目

.git文件不要删了

```shell
$ git remote -v # 先查看远程连接是不是自己的
$ git remote remove origin # 如果不是删除该远程连接 如果没有就不用管
$ git remote add origin 你的连接名 # 修改为你的远端连接

# 在idea中将要上传的文件commit

$ git pull origin master # 拉取并合并到本地，如果有冲突，手动处理冲突，然后add commit; 如果报错查看报错的文件，将未加入暂存区的删除该文件再pull，如果提示没有共同提交历史执行第八行代码，没有提示就不需要执行第八行代码
$ git pull origin master --allow-unrelated-histories # 拉取并强制合并两个独立的历史

$ git push origin master # 上传到远端
```
